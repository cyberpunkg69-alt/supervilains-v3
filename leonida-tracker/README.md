# LEONIDA TRACKER V2.0 — 20 novembre 2026

Un compagnon GTA VI non officiel, utilisable dans Chrome sur Android ou sur ordinateur.

## Fonctions
- Fond de carte communautaire YANIS V15 depuis les tuiles GTADB.ORG, affichées directement sans iframe (connexion Internet requise).
- Bascule Relief / Grille ; défilement, zoom tactile, sélection des marqueurs.
- Carte et carnet avec catégories, filtres, marqueurs cliquables et notes.
- État « trouvé », favoris, liste de chasse, statistiques et sauvegardes JSON.
- La progression V1/V1.1 est conservée grâce à la même clé de stockage local.

## Limites importantes
Les données FullSweep décrivent une carte de 3344 × 4820 pixels ; les tuiles YANIS V15 proviennent d'un autre cadrage. La superposition actuelle des marqueurs sur la mosaïque YANIS est un **repère visuel provisoire, pas un placement géographiquement étalonné**. Il faut ouvrir chaque lieu sur la carte FullSweep pour vérifier sa position. Le catalogue ne correspond pas encore à tous les secrets du jeu et ses labels de fiabilité sont respectés.
