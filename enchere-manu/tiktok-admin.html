👑 TikTok LIVE — Commandes privées

Choisis le compte TikTok qui est réellement en direct. Le bandeau s'affiche immédiatement sur MANU Enchères pour tous les visiteurs. Une notification est demandée aux abonnés lors du passage de OFF à LIVE.

Ce code reste dans cette page. Ne le publie pas dans le chat, et ne partage ce panneau qu'avec les personnes autorisées. Chaque compte a un bouton indépendant.

Un LIVE activé manuellement expire au bout de 8 heures par sécurité, sauf si tu l'arrêtes avant. Si le direct dure plus longtemps, réactive-le. La détection automatique externe n'est pas encore connectée.
