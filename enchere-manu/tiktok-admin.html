🔐 Sécurité du panneau LIVE

Tu peux remplacer ton code privé à tout moment. Entre d'abord le code actuel dans le champ ci-dessus : il est nécessaire pour autoriser le changement.

Enregistre-le dans ton gestionnaire de mots de passe. Le précédent code ne fonctionne plus. Celui-ci ne sera plus affiché après avoir quitté ou rechargé la page.

Si tu perds ton code et n'as aucune copie, ce bouton ne pourra pas le récupérer : une réinitialisation côté administrateur sera nécessaire.

Un LIVE activé manuellement expire au bout de 8 heures par sécurité, sauf si tu l'arrêtes avant. Si le direct dure plus longtemps, réactive-le. La détection automatique externe n'est pas encore connectée.
